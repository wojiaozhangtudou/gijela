## 验证步骤（手工验收）
1. 启动开发服务器（PowerShell）：

```powershell
pnpm install
pnpm run dev
```

2. 打开浏览器访问开发地址（示例）： `http://localhost:5174/`，进入“菜单管理”页面。

3. 页面行为检查：
   - 页面默认显示树状表格（顶层节点可展开）。
   - 列表中的“名称”列，展开折叠图标与名称在同一行。
   - 搜索框填写名称并点击搜索，树会进行筛选并保留父路径。

4. 展开/折叠交互：
   - 点击“展开全部”按钮，表格应全部展开（控制台会打印 `expandAll: setting isExpandAll=true...`）
   - 点击“折叠全部”按钮，表格应全部收起（控制台会打印 `collapseAll: setting isExpandAll=false...`）
   - 若按钮没有效果，请打开浏览器 DevTools 控制台并复制点击按钮时的日志。

5. 新增/编辑菜单：
   - 点击“新增”打开对话框：应能选择类型（D/M/B）、父级（仅 D / M 项，显示层级前缀 `└─ `），填写名称与路径，状态开关默认“启用”。
   - 编辑某一行：父级下拉中应排除当前节点及其子孙，避免选择成自己的子孙。
   - 点击保存后，Network 面板中对应请求的 payload 应包含 `parentId`, `type`, `status` 字段。若后端要求数值类型，请告知以便我把 `status` 转为数字发送。

6. 状态切换：
   - 在表格中点击状态开关会弹出确认框，确认后调用状态更新接口并刷新列表。
   - 开关的显示文案使用 i18n（例如中文显示“启用/禁用”）。
