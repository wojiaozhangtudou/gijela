# BUG-20260509-002 清空日志后 SRE 概览仍显示旧指标

## 1. 问题现象
- 发生时间：2026-05-09
- 触发条件：执行“一键清空日志”后，立即查看 SRE 概览。
- 用户影响：页面仍显示平均 QPS、错误率等旧指标，误导排障判断。

## 2. 影响范围
- 模块：日志清理接口、Redis 查询缓存、SRE 概览统计
- 环境：开发环境
- 严重级别：P1

## 3. 复现步骤
1. 进入日志看板并产生若干日志数据。
2. 点击“一键清空日志”。
3. 立刻刷新或重新进入 SRE 概览。

## 4. 预期结果
- 清空后概览指标应与当前空日志数据一致。

## 5. 实际结果
- 概览仍展示旧的平均 QPS、P95 等缓存数据。

## 6. 根因分析
- 清日志流程只删除 ES 数据，没有同步清理 Redis 查询缓存。
- 部分实时指标仍走缓存，导致数据删除后短时间内继续读到旧值。

## 7. 修复方案
- 在清日志接口完成后同步清理日志缓存。
- 对 qps、errorRate、p95、totalTokens 等实时指标改为绕过缓存直接查询。
