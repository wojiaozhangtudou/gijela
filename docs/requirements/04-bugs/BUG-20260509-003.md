# BUG-20260509-003 日志明细缺少模型输出文本与逐段记录

## 1. 问题现象
- 发生时间：2026-05-09
- 触发条件：查看一次流式对话在日志看板中的详细记录。
- 用户影响：日志中看不到完整输出文本，且无法按流式分段观察 token 与返回片段，排查价值不足。

## 2. 影响范围
- 模块：聊天编排服务、运行时日志写入、ES 查询映射、审计/追踪页面
- 环境：开发环境
- 严重级别：P1

## 3. 复现步骤
1. 发起一次流式对话。
2. 打开日志看板的 Audit 或 Trace 详情。
3. 查看是否存在模型输出文本和逐段日志。

## 4. 预期结果
- 日志应能看到模型输出文本。
- 流式过程应按 delta 记录对应文本与 token 变化。

## 5. 实际结果
- 旧日志仅有粗粒度状态记录，缺少输出文本和逐段 token 明细。

## 6. 根因分析
- 旧运行时日志只在关键阶段记录事件，没有把流式增量内容单独落库。
- 查询层与前端表格也未暴露 `outputText`、`eventType`、`logType` 等字段。

## 7. 修复方案
- 在运行时日志中新增 `outputText` 字段。
- 每个流式 delta 产生一条 `chat.delta` 日志，记录增量文本及估算 token。
- Trace/Audit 页面补充展示 `outputText`、`eventType`、`logType`。
