# BUG-20260509-001 对话 Tokens 字段为空

## 1. 问题现象
- 发生时间：2026-05-09
- 触发条件：使用 OpenAI 兼容流式模型进行对话，前端消息区或日志明细中的 `Tokens` 字段为空。
- 用户影响：无法观察一次对话的 token 消耗，影响联调与成本排查。

## 2. 影响范围
- 模块：OpenAI 兼容 SDK SSE 解析、聊天编排链路、前端展示
- 环境：开发环境
- 严重级别：P0

## 3. 复现步骤
1. 使用 OpenAI 兼容模型发起一次流式对话。
2. 等待模型完成输出。
3. 查看聊天界面或日志中 `Tokens` 展示。

## 4. 预期结果
- 对话完成后可看到本次请求对应的 token 使用量。

## 5. 实际结果
- 模型文本返回正常，但 `Tokens` 字段为空。

## 6. 根因分析
- OpenAI 兼容流式响应中，`usage` 可能出现在 `finish_reason=stop` 之后、`[DONE]` 之前的独立 chunk。
- 旧解析逻辑在收到 `stop` 后过早发出完成事件，导致后续仅包含 `usage` 的 chunk 被忽略。

## 7. 修复方案
- 调整 SSE 解析逻辑：仅在收到 `[DONE]` 时发出最终完成事件。
- 为“`usage` 晚于 `stop`”补测试，确保兼容 qwen-plus 等 OpenAI 兼容流式模型。
