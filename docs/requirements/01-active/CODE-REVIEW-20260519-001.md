## 一、关键问题汇总

### 🔴 Critical：设计文档与实现不一致

#### 问题 1.1：Completion 工作流输入字段名不一致

**位置**：
- 文档：[ARCH-REVIEW-20260519-004.md](./ARCH-REVIEW-20260519-004.md) 附录 A.2（第 410 行）
- 实现：[ChatflowConversationServiceImpl.java](../../gijela-core/gijela-core-chat-flow/src/main/java/com/gijela/morpheus/chatflow/service/impl/ChatflowConversationServiceImpl.java)（197-199 行）

**问题描述**：
```
文档声称传入的输入字段为：
  { query, chat_history, conversation_id }

实际代码传入的字段为：
  { question, history, ... (+ 其他 workflowInputs) }
```

**影响范围**：
- ❌ 工作流设计者会根据文档期望 `query` 字段，但实际收到 `question`
- ❌ 消息历史字段名不同可能导致工作流解析错误
- ❌ 缺少 `conversation_id` 字段，工作流无法标识对话上下文

**修复建议**：
1. **方案 A**（推荐）：修改代码匹配文档意图
   ```java
   inputs.put("query", content);                    // 改 question → query
   inputs.put("chat_history", buildHistoryJson(...)); // 改 history → chat_history
   inputs.put("conversation_id", session.getSessionId()); // 新增
   ```

2. **方案 B**：修改文档匹配实现
   ```markdown
   Input: { question, history, ... + session.workflowInputs }
   ```

**优先级**：P0（影响工作流正常执行）

### 🔴 Critical：缺少系统变量注入

#### 问题 1.2：Phase 2 设计的系统变量未实现

**位置**：
- 设计说明：[ARCH-REVIEW-20260519-003.md](./ARCH-REVIEW-20260519-003.md) 第 10 节
- 实现缺口：[ChatflowConversationServiceImpl.java](../../gijela-core/gijela-core-chat-flow/src/main/java/com/gijela/morpheus/chatflow/service/impl/ChatflowConversationServiceImpl.java)（197-199 行）

**问题描述**：
设计规划中提到 Phase 1 需要自动注入系统变量：
```
sys.query          → 最后一条用户消息
sys.chat_history   → 最近 10 轮对话历史（JSON）
sys.conversation_id → Session ID
```

实际实现只有：
```
question  → 用户消息内容 ✅
history   → 对话历史 ✅
（无 sys.* 前缀，也无 conversation_id）❌
```

**影响范围**：
- 工作流无法通过 `sys.conversation_id` 识别对话
- 与设计规划不符，Phase 2 实施会有冲突
- 前端假设问题追踪时缺少关键的会话上下文

**修复建议**：
```java
// 改为系统变量命名规范
Map<String, Object> sysInputs = new LinkedHashMap<>();
sysInputs.put("sys.query", content);
sysInputs.put("sys.chat_history", buildHistoryJson(...));
sysInputs.put("sys.conversation_id", session.getSessionId());

inputs.putAll(sysInputs);
inputs.putAll(readMap(session.getWorkflowInputs())); // 用户输入覆盖
```

**优先级**：P0（设计缺口，需立即修复）

### 🟠 Major：异常处理不完整

#### 问题 1.3：Controller 缺少完整的异常捕获

**位置**：
- [ChatflowConversationController.java](../../gijela-core/gijela-core-chat-flow/src/main/java/com/gijela/morpheus/chatflow/controller/ChatflowConversationController.java)（82-92 行）

**问题描述**：
```java
@PostMapping("/completions")
public ApiResponse<ChatflowCompletionVO> completion(@RequestBody @Valid ChatflowCompletionDTO dto) {
    try {
        return ApiResponse.ok(conversationService.completion(dto));
    } catch (NoSuchElementException ex) { ... }
    catch (IllegalArgumentException ex) { ... }
    catch (IllegalStateException ex) { ... }
    // 缺少其他异常捕获！
}
```

**可能遗漏的异常**：
- `IOException`：工作流 JSON 序列化/反序列化错误
- `RuntimeException`：工作流服务调用异常
- `TimeoutException`：工作流执行超时
- `Exception`：兜底异常

**影响范围**：
- 未捕获的异常会返回 500 错误，缺少业务友好的错误信息
- 日志会输出完整堆栈，可能泄露敏感信息
- 前端无法区分错误类型

**修复建议**：
```java
@PostMapping("/completions")
public ApiResponse<ChatflowCompletionVO> completion(@RequestBody @Valid ChatflowCompletionDTO dto) {
    try {
        return ApiResponse.ok(conversationService.completion(dto));
    } catch (NoSuchElementException ex) {
        return ApiResponse.fail(ErrorCode.NOT_FOUND.getCode(), ex.getMessage(), null);
    } catch (IllegalArgumentException ex) {
        return ApiResponse.fail(ErrorCode.INVALID_ARGUMENT.getCode(), ex.getMessage(), null);
    } catch (IllegalStateException ex) {
        return ApiResponse.fail(ErrorCode.ILLEGAL_STATE.getCode(), ex.getMessage(), null);
    } catch (JsonProcessingException ex) {
        logger.error("工作流输入序列化失败", ex);
        return ApiResponse.fail(ErrorCode.INTERNAL_ERROR.getCode(), "数据处理错误", null);
    } catch (TimeoutException ex) {
        logger.error("工作流执行超时", ex);
        return ApiResponse.fail(ErrorCode.TIMEOUT.getCode(), "工作流执行超时（60s）", null);
    } catch (Exception ex) {
        logger.error("工作流执行异常", ex);
        return ApiResponse.fail(ErrorCode.INTERNAL_ERROR.getCode(), "内部服务错误", null);
    }
}
```

**优先级**：P1（影响稳定性和错误报告）
