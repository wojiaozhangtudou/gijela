# BUG-20260509-EXAMPLE 日志看板导出后文件名乱码

## 1. 问题现象
- 发生时间：2026-05-09
- 触发条件：中文筛选条件下，从浏览器下载导出文件。
- 用户影响：文件下载成功，但文件名显示乱码，影响识别与归档。

## 2. 影响范围
- 模块：前端下载处理、后端响应头编码
- 环境：开发环境 / 测试环境
- 严重级别：P2

## 3. 复现步骤
1. 打开日志看板。
2. 选择包含中文条件的筛选项并点击导出。
3. 查看浏览器下载文件名。

## 4. 预期结果
- 文件名按中文正常展示，且包含日期或筛选标识。

## 5. 实际结果
- 文件内容正常，但文件名出现乱码。

## 6. 根因分析
- 后端 `Content-Disposition` 编码与前端解析规则不一致，未统一采用浏览器兼容写法。

## 7. 修复方案
- 后端统一输出兼容编码的文件名。
- 前端下载逻辑优先解析标准文件名字段，失败时使用兜底命名。
