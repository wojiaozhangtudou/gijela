# DEV-FEEDBACK-20260430-001 知识入库缺少向量集合初始化链路

## 一、问题分类
- 架构缺口

## 二、问题位置
- 触发日志：`Collection chat_knowledge doesn't exist`
- 涉及文件：
  - `gijela-core/gijela-core-chat/src/main/java/com/gijela/morpheus/chat/adapter/mcp/KnowledgeSearchGateway.java`
  - `gijela-core/gijela-core-chat/src/main/java/com/gijela/morpheus/chat/controller/ChatController.java`
  - `gijela-core/gijela-core-chat/src/main/resources/application.yml`

## 三、影响范围
- 功能：文件/文本知识入库失败，导致检索链路无可用数据。
- 稳定性：新环境首次部署必须手工预建集合，易出现联调阻塞。

## 四、严重级别
- Blocker

## 五、问题说明
- 现有入库逻辑默认集合已存在，未在代码层处理“首次初始化”场景。
- Qdrant 集合创建依赖向量维度与距离度量，缺少统一入口会导致环境不一致。

## 六、修正建议
1. 在入库流程增加集合存在性检查，并在缺失时自动创建。
2. 提供显式初始化接口，允许按维度和距离参数初始化集合。
3. 配置化默认距离与是否自动创建开关，降低环境漂移风险。

## 七、临时绕行方案
- 发布前可通过 Qdrant 控制台/脚本手工创建集合；当前版本已支持接口化初始化，建议改为接口化。

## 八、处理结果
- 已完成：
  - 自动检查并按首个向量维度创建集合。
  - 新增接口 `POST /api/v1/chat/knowledge/collection/init?vectorSize=...&distance=...`。
  - 新增配置 `vector-distance`、`auto-create-collection`。
  - 前端知识页面新增“创建/校验集合”操作。
- 验证：
  - 后端测试 `KnowledgeSearchGatewayTest`、`ChatControllerTest` 通过。
  - 前端 `pnpm typecheck`、`pnpm build` 通过。

## 九、已落盘位置
