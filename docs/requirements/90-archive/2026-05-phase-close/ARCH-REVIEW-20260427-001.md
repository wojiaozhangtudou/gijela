# ARCH-REVIEW-20260427-001 架构可落地性评审（针对 REQ-20260427-002）

## 一、可落地性结论
- 结论：**有条件可落地**。
- 依据：核心能力定义较完整（SSE、Function Calling、插件化、热插拔已明确），但仍有 5 项关键参数未拍板，会直接影响实现边界与验收可执行性。

## 二、关键问题与调整建议
1. 目标与范围轻微冲突
   - 位置：二、范围 In Scope 第 2 条；十三、问题 1
   - 风险：目标写“支持多模型提供商”，范围又限定“单一 OpenAI 兼容固定配置”，易导致对外预期偏差。
   - 建议：将“多模型提供商接入”改为“预留多提供商扩展能力，首期固定单提供商”。
   - 优先级：P0

2. P0/P1 分层重复
   - 位置：二、范围“关键治理能力”；三、功能清单 P1-1
   - 风险：限流/熔断到底是首期必须还是次迭代，影响代码设计与发布时间。
   - 建议：明确为“P0 基础限流 + P1 熔断”；并在验收标准补对应条目。
   - 优先级：P0

3. 架构形态未拍板（SDK vs 网关）
   - 位置：六、待确认问题 5；十四、优先确认项 1
   - 风险：插件热插拔、治理位置、部署模型、运维职责都不同，可能返工。
   - 建议：已确认仅 `SDK`（对标 LangChain4j），不纳入网关化路线。
   - 优先级：P0

4. 非功能指标不可验收
   - 位置：四、非功能需求
   - 风险：P95、TTFB、QPS、错误率未量化，测试无法判定通过/不通过。
   - 建议：先给默认门槛：
     - P95（非流式）<= 3s（业务侧）
     - TTFB（流式）<= 800ms
     - 错误率 <= 1%
     - 峰值并发与 QPS 给出最小目标值（如 200 并发 / 50 QPS，按现网再调）
   - 优先级：P0

5. MCP/Skills/A2A 边界不清
   - 位置：六、待确认问题 6
   - 风险：若首期同时做注册发现/权限编排，复杂度会显著上升。
   - 建议：首期仅“调用能力 + 示例插件”；注册发现、跨节点路由、细粒度权限编排放 P1。
   - 优先级：P0

6. 成本统计粒度未定
   - 位置：六、待确认问题 4
   - 风险：预算告警与报表模型无法落地，后续补改成本高。
   - 建议：首期固定“租户级”，应用级作为辅助，用户级放 P1。
   - 优先级：P1

7. 热插拔缺少运行约束
   - 位置：三、功能清单 P0-10/11
   - 风险：运行中替换插件可能造成请求中断或状态不一致。
   - 建议：补充约束：新请求走新插件，进行中请求保持旧实例直至完成；失败自动回滚上一版本。
   - 优先级：P0

8. 安全与密钥策略缺少细节
   - 位置：四、非功能需求“安全”
   - 风险：密钥泄漏、审计字段不足，难满足合规审查。
   - 建议：明确密钥轮转周期、最小审计字段（tenantId、pluginId、toolName、requestId、errorCode）。
   - 优先级：P1

## 三、最小落地路径（MVP）
- 第一步：拍板 4 个 P0 决策（架构形态、限流熔断分层、MCP/Skills/A2A 边界、性能门槛）。
- 第二步：按 SDK 方案实现主链路（固定 OpenAI 配置 + SSE + Function Calling + 基础限流/重试）。

- 第四步：补观测与验收（指标、压测、故障注入、审计）。

## 七、四项阻塞在业界的常见做法
1. 部署形态（SDK / 网关）
   - 本项目决策：**仅 SDK**。
   - 说明：网关化不在当前项目范围内。

2. 性能阈值（QPS/并发/P95/TTFB/错误率）
   - 常见做法：先给“保守默认值”，上线后按压测与生产观测滚动调整。
   - 常见初始门槛（文本场景）：
     - P95（非流式）<= 3s
     - 流式 TTFB <= 800ms
     - 错误率 <= 1%
     - QPS/并发先给最小目标（如 50 QPS、200 并发）再迭代。

3. 成本统计粒度
   - 常见顺序：**租户级优先**（结算与限额最直接）-> 应用级（运营分析）-> 用户级（精细化治理）。
   - 首期建议：预算与告警按租户级生效，应用级仅做观测看板。

4. 热插拔运行约束
   - 常见策略：**新请求走新版本，在途请求留在旧版本直至完成**（graceful switch）。
   - 回滚触发：健康检查失败、错误率超阈值、关键路径超时激增。
   - 回滚动作：自动回切上一个稳定版本，并记录审计事件。
