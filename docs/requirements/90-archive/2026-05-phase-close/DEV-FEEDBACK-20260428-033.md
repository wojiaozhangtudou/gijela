# DEV-FEEDBACK-20260428-033 会话列表未显式标记失败回合

## 一、问题分类
- 体验缺口

## 二、问题位置
- 涉及文件：
  - `gijela-bloom/gijela-bloom-chat/src/views/ChatPage.vue`

## 三、影响范围
- 功能：消息窗口已显示失败回合，但会话列表无法快速识别异常会话。
- 可维护性：运营与排障需要逐个点进会话确认，效率较低。

## 四、严重级别
- Minor

## 五、问题说明
- 当前会话列表仅展示标题与摘要。
- 即使摘要包含失败语义，界面也无显式状态标签，识别成本高。

## 六、修正建议
1. 会话列表按摘要语义识别失败会话（如包含“失败回合”/`ERROR:`）。
2. 增加“含失败回合”标签与弱高亮样式。
3. 保持不改接口契约，优先前端最小改动落地。

## 七、临时绕行方案
- 无需绕行，本轮已修复。

## 八、处理结果
- 已实现：
  - 会话列表新增失败态判断 `isFailedSession()`。
  - 失败会话显示 `含失败回合` 标签并使用红色弱高亮背景。
- 已验证：
  - `pnpm typecheck` 通过。
  - `pnpm build` 通过。
- 当前状态：已关闭。
