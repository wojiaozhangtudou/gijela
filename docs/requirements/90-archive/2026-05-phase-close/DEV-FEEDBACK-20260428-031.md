# DEV-FEEDBACK-20260428-031 前端未显式标记失败回合

## 一、问题分类
- 体验缺口

## 二、问题位置
- 涉及文件：
  - `gijela-bloom/gijela-bloom-chat/src/store/chat.ts`
  - `gijela-bloom/gijela-bloom-chat/src/components/ChatWindow.vue`
  - `gijela-bloom/gijela-bloom-chat/src/types/chat.ts`

## 三、影响范围
- 功能：对话失败后，用户仅看到错误提示，不易定位对应失败回合。
- 可维护性：问题排查时，历史消息缺少“失败语义”标记。

## 四、严重级别
- Major

## 五、问题说明
- 原实现仅通过 `lastError` 显示错误文本。
- 同步/流式失败时，消息列表没有结构化失败标识，无法快速识别哪一轮失败。

## 六、修正建议
1. 扩展消息模型，增加失败标记字段。
2. 在同步与流式失败路径显式标记当前用户回合为失败。
3. 在消息列表中增加“失败回合”标签和视觉样式。

## 七、临时绕行方案
- 无需绕行，本轮已修复。

## 八、处理结果
- 已实现：
  - `ChatMessage` 新增 `failed?: boolean`。
  - `sendSync` 失败时标记本轮用户消息并插入失败 assistant 消息。
  - `sendStream` 在 `error` 事件与网络异常时统一标记失败回合，并保留部分响应文本。
  - UI 显示 `失败回合` 标签与红色失败样式。
- 已验证：
  - `pnpm typecheck` 通过。
  - `pnpm build` 通过。
- 当前状态：已关闭。
