# DEV-FEEDBACK-20260428-032 历史回放未恢复失败回合标记

## 一、问题分类
- 体验缺口

## 二、问题位置
- 涉及文件：
  - `gijela-bloom/gijela-bloom-chat/src/store/chat.ts`

## 三、影响范围
- 功能：实时会话中可见失败回合，但重新进入会话后失败标记丢失。
- 可维护性：历史问题排查时，用户无法快速定位失败回合。

## 四、严重级别
- Major

## 五、问题说明
- 失败回合语义目前通过消息内容（如“失败回合：...”）持久化。
- 历史加载时仅做 role/content 映射，没有恢复 `failed` 标记，导致 UI 丢失失败态样式。

## 六、修正建议
1. 在历史映射阶段识别失败 assistant 消息。
2. 对失败 assistant 及其最近一条 user 消息恢复 `failed` 标记。
3. 保持实时链路与历史回放显示一致。

## 七、临时绕行方案
- 无需绕行，本轮已修复。

## 八、处理结果
- 已修复：`loadMessages()` 改为 `mapHistoryMessages()`，恢复失败回合标记。
- 已实现规则：
  - assistant 内容以“失败回合：”或“失败回合（已收到部分响应）：”开头时标记失败；
  - 自动回溯并标记最近一条 user 消息为失败。
- 已验证：
  - `pnpm typecheck` 通过。
  - `pnpm build` 通过。
- 当前状态：已关闭。

## 九、已落盘位置
