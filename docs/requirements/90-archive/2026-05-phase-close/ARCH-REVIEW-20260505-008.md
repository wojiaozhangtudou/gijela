### 一、可落地性结论
- 结论：**可落地**。
- 依据：
  1. 已明确“所有入库都必须人工确认”；
  2. 已从设计与执行文档中移除 `autoImport` 语义，避免规则冲突；
  3. 流程统一为“抽取预览 -> `/import` 确认入图”，实现边界清晰。

### 二、关键问题与调整建议
1. 问题：历史文档存在自动入图语义残留
   - 位置：章节“模式切换 / 入图控制 / 调试面板 / Gate”
   - 风险：前后端按不同版本实现，联调时出现绕过确认路径。
   - 建议：统一口径为“抽取接口不写图，写图仅发生在 `/import`”。
   - 优先级：P0

2. 问题：验收口径需同步收敛
   - 位置：P0 Gate 与拍板单
   - 风险：验收标准不一致，导致上线门槛虚化。
   - 建议：将 G1 固化为“任意模式下，未确认不得入图”。
   - 优先级：P0

### 三、最小落地路径（MVP）
- 第一步：按 [ARCH-REVIEW-20260505-007.md](./ARCH-REVIEW-20260505-007.md) 实施后端 `/extract/*` 与 `/import` 分离链路。
- 第二步：前端仅保留“确认入图”触发路径，不提供自动入图控件。
- 第三步：联调验收以 G1~G8 为准，重点验证“无确认不入图”。

### 四、待拍板决策

2. 是否确认前端不再暴露任何自动入图开关。
