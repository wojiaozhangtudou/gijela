# DEV-FEEDBACK-20260429-001 会话列表缺少失败会话快速筛选

## 一、问题分类
- 体验缺口

## 二、问题位置
- 涉及文件：
  - `gijela-bloom/gijela-bloom-chat/src/views/ChatPage.vue`

## 三、影响范围
- 功能：会话列表虽可显示“含失败回合”标签，但无法一键聚焦异常会话。
- 可维护性：排障场景需要手动浏览全部会话，效率低。

## 四、严重级别
- Minor

## 五、问题说明
- 失败会话在会话列表可见，但缺少筛选控件。
- 当会话数量增长时，异常会话检索成本明显上升。

## 六、修正建议
1. 在会话列表增加“仅失败/全部”切换开关。
2. 在筛选结果为空时显示专属空态文案（例如“暂无失败会话”）。
3. 复用现有失败判定函数，避免重复规则分叉。

## 七、临时绕行方案
- 无需绕行，本轮已修复。

## 八、处理结果
- 已实现：
  - 会话列表头部新增 `el-switch`，支持“仅失败/全部”切换。
  - 新增 `filteredSessions` 计算属性，复用 `isFailedSession()` 判定。
  - 筛选为空时显示“暂无失败会话”。
- 已验证：
  - `pnpm typecheck` 通过。
  - `pnpm build` 通过。
- 当前状态：已关闭。
