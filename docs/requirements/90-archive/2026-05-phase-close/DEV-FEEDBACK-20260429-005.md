# DEV-FEEDBACK-20260429-005 chat 模块缺少知识库构建入库链路

## 一、问题分类
- 架构缺口

## 二、问题位置
- 来源：联调阶段用户反馈“只有检索没有构建知识库”
- 涉及文件：
  - `gijela-core/gijela-core-chat/src/main/java/com/gijela/morpheus/chat/adapter/mcp/KnowledgeSearchGateway.java`
  - `gijela-core/gijela-core-chat/src/main/java/com/gijela/morpheus/chat/controller/ChatController.java`
  - `gijela-core/gijela-core-chat/src/main/java/com/gijela/morpheus/chat/service/KnowledgeIngestionService.java`
  - `gijela-core/gijela-core-chat/src/main/resources/application.yml`

## 三、影响范围
- 功能：只能召回已存在向量，无法从业务文本构建知识点并写入向量库。
- 可运维性：知识更新依赖外部脚本，联调和排障成本高。

## 四、严重级别
- Major

## 五、问题说明
- 现有 `knowledge.search` 仅实现 query 向量化 + Qdrant `/points/search`。
- 缺少“文本切块 -> embedding -> Qdrant upsert”主链路，导致知识库无法在 chat 模块内闭环构建。

## 六、修正建议
1. 新增知识入库接口：`POST /api/v1/chat/knowledge/index`。
2. 新增入库服务，统一执行切块、向量化、Qdrant upsert。
3. 将分块参数下沉到配置：`index-chunk-size`、`index-chunk-overlap`。

## 七、临时绕行方案
- 在未发布前，继续使用离线脚本向 Qdrant 导入数据；发布后建议统一走入库接口。

## 八、处理结果
- 已完成落地并通过验证：
  - `KnowledgeSearchGateway` 新增 `indexText(...)`（切块 + embedding + Qdrant upsert）。
  - 新增 `KnowledgeIngestionService` 与 `DefaultKnowledgeIngestionService`。
  - `ChatController` 新增 `POST /api/v1/chat/knowledge/index`。
  - 单测通过：`KnowledgeSearchGatewayTest`、`ChatControllerTest`。
  - 编译通过：`mvn -pl gijela-core-chat -am -DskipTests compile`。
- 当前状态：已关闭。
