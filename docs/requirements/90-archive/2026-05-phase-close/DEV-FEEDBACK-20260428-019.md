## 影响范围
- 功能：调用方在可变 metadata 中显式写入 `AUTO_TOOL_CONTINUE=null` 时，若回退语义不明确，可能导致续跑策略偏差。
- 稳定性：动态参数组装链路常见 null 值，需固定默认行为避免灰度波动。

## 严重级别
- Minor

## 现象
- 代码逻辑在 `auto == null` 时保持默认 `true`。
- 之前缺少“key 存在但值为 null”的直接单测。

## 修正建议
- 增加回归测试，显式锁定 null 值回退为 `true`。

## 临时绕行方案
- 调用方避免传空值键；若无法避免，按当前语义可预期为启用自动续跑。
