   - 建议：Day1 只做“后端契约 + 后端骨架 + 前端 API 占位”，页面细节后置。
   - 优先级：P0

2. 问题：若不先落错误码与幂等校验，主链路验收无意义
   - 位置：`/import`
   - 风险：重复确认、超限失败场景无法闭环。
   - 建议：Day1 必须同时落 `Idempotency-Key` 校验与超限错误码常量。
   - 优先级：P0
