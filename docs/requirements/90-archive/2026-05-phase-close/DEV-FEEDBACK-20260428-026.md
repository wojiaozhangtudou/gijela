# DEV-FEEDBACK-20260428-026 JDK21 下 Mockito inline 自附着失败导致测试不可执行

## 一、问题分类
- 实现风险

## 二、问题位置
- 涉及文件：
  - `gijela-core/gijela-core-chat/pom.xml`
  - `gijela-core/gijela-core-chat/src/test/resources/mockito-extensions/org.mockito.plugins.MockMaker`
- 触发场景：
  - 在 JDK 21 环境执行 chat 关键测试集时，Mockito inline mock maker 需要 ByteBuddy 动态附着，出现 `Could not self-attach to current VM using external process`。

## 三、影响范围
- 功能：不影响运行时功能。
- 稳定性：影响测试执行稳定性，导致关键测试集整体失败。
- 可维护性：不同 JDK/运行环境下测试行为不一致，增加回归成本。

## 四、严重级别
- Major

## 五、问题说明
- 仅配置 `-XX:+EnableDynamicAgentLoading` 在当前环境仍可能失败。
- 根因是 Mockito 默认使用 inline mock maker，依赖 agent 自附着能力；在部分 JDK/安全策略下不可用。

## 六、修正建议
1. 测试默认切换到 `mock-maker-subclass`，避免依赖动态附着能力。
2. 保留 surefire JVM 参数作为兼容兜底。
3. 后续若需 mock final/static，再按需引入独立测试 profile。

## 七、临时绕行方案
- 无需绕行，本轮已修复。

## 八、处理结果
- 已新增文件：
  - `src/test/resources/mockito-extensions/org.mockito.plugins.MockMaker`
  - 内容：`mock-maker-subclass`
- 已验证通过：
  - `mvn -pl gijela-core-chat "-Dtest=ChatOrchestratorServiceImplTest,ChatControllerTest,ChatHistoryQueryServiceImplTest,RedisConversationStoreTest,InMemoryConversationStoreTest" test`
- 当前状态：已关闭。
