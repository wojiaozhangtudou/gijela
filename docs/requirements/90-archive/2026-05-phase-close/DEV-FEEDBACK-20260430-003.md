## 根因
- `references` 仅在响应阶段透传，未持久化到 `chat_message` 表。
- 历史查询固定返回 `references=null`，导致刷新回放后前端无引用信息。

## 修正建议
1. 在 `chat_message` 增加 `references_json` 字段用于持久化 assistant 引用。
2. assistant 落库改为写入 `references_json`。
3. 历史回放时解析 `references_json` 并回填 `ChatHistoryMessageResponse.references`。
4. 同步与流式两条 assistant 落库路径统一调用带 references 的落库接口。
