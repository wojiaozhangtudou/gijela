### 一、可落地性结论
- 结论：**有条件可落地（进入“拍板即可开工”阶段）**。
- 依据：
  1. 关键风险已在 003/004 识别并 Gate 化；
  2. 当前阻断点主要是“参数和规则未冻结”，不是架构不可行；
  3. 给出默认冻结值后，可直接落 G1~G4 骨架开发。

### 二、关键问题与调整建议
1. 问题：入图确认规则未冻结
   - 位置：`extractMode` 与入图流程
   - 风险：流程含义不一致，前后端行为分裂。
   - 建议（冻结值）：
     - `LLM_ONLY`：抽取仅预览，入图必须确认
     - `LLM_RULES`：抽取仅预览，入图必须确认
     - `LLM_HUMAN`：抽取仅预览，入图必须确认
   - 优先级：P0

2. 问题：文件抽取是否同步未冻结
   - 位置：`/extract/file`
   - 风险：同步接口若无阈值控制易超时。
   - 建议（冻结值）：
     - 文件抽取一律同步返回预览；
     - 超过阈值直接返回超限错误码（不进入后台任务）。
   - 优先级：P0

3. 问题：幂等键规则未冻结
   - 位置：`/import`
   - 风险：重复提交写脏图。
   - 建议（冻结值）：
     - 优先使用请求头 `Idempotency-Key`；
    - 缺省时回退 `previewId + graphSpace + importMode` 组合键；
     - 幂等窗口 24h。
   - 优先级：P0

4. 问题：关系业务主键算法未冻结
   - 位置：关系模型
   - 风险：删除/分页定位不稳定。
   - 建议（冻结值）：
     - `relationshipId = SHA256(tenantId|graphSpace|sourceNormalized|targetNormalized|descriptionNormalized)`
   - 优先级：P0

5. 问题：容量阈值未冻结
   - 位置：抽取接口
   - 风险：资源不可控。
   - 建议（冻结值）：
     - 文件大小：<= 10MB
     - 文本长度：<= 50,000 字符
     - 预览上限：实体 <= 300，关系 <= 800
     - `maxTokens` 上限：4096（调试白名单可到 8192）
   - 优先级：P1

6. 问题：安全边界未冻结
   - 位置：`promptOverride`
   - 风险：越权调试与高成本调用。
   - 建议（冻结值）：
     - 权限：`graph:debug-prompt`
     - 长度：<= 8KB
     - 仅灰度账号可用（首版）
     - 必记审计字段：`operator, tenantId, graphSpace, extractMode, promptHash, model, tokenUsage, durationMs`
   - 优先级：P1

### 三、最小落地路径（MVP）
- 第一步：冻结本文件中的 6 组参数（形成实施基线）。
- 第二步：后端实现 G1~G4（模式冲突、同步入参保护、幂等、schema init）。
- 第三步：前端落 GraphPage 基础流程（文本/文件抽取、预览、确认入图）。
- 第四步：联调后灰度放开 `promptOverride`。

### 四、待拍板决策
1. 已确认：所有模式都必须人工确认后入图。
2. 已确认：文件抽取同步化；首版不额外设置应用层同步超时阈值，仅控制输入上限。
3. 已确认：幂等窗口 24h。
4. 已确认：`relationshipId` 使用哈希字段组合。
5. 已确认：首版容量阈值为 10MB / 50k / 300 / 800 / 4096。
